## 📖 简介

**阳光学习能量站**是一款面向小学 1–6 年级的**纯本地离线学习打卡工具**：家长按课本拆解单元任务，孩子完成任务赚「☀️ 阳光值」、每日打卡攒连击、用阳光在兑换商店换现实奖励（家长审批码确认后仅记账）。

产品目标不是判题与排名，而是让孩子**看见自己的学习进度**，并因正向激励而**主动打开工具**——把「今天学什么」交给孩子自己想清楚。

> **设计约束**：整个应用就是一个 `阳光学习能量站.html`（约 237 KB，243,113 字节）——HTML + CSS + JS 全部内联，无 CDN、无构建步骤、无第三方库，默认零网络请求，双击即用。

## ✨ 特性

**孩子侧 · 学习与激励**

- 📚 **8 大学科导航**：语文 / 数学 / 英语 / 科学 / 道法 / 体育 / 音美 / 综合，按单元拆解任务卡片，勾选即 +5☀️
- 📅 **周期任务**：一次性 / 每日 / 每周（周一重置）/ 工作日 / 临时五种周期自动重置，「每天做」的重复激励不丢历史阳光
- ✅ **每日打卡**：+20☀️ 与连续天数累计，防重复计分、断签自动归零，里程碑与「完美周」额外加成
- 🎯 **当日完成度里程碑**：可见任务完成到 50% / 75% / 100% 分别追加 +2 / +5 / +10☀️，每档每日只发一次
- 🌟 **今日推荐**：自动从未完成任务中挑 3 项，降低「不知道学什么」的选择成本
- 🏆 **成长体系**：阳光值 → 5 档等级（嫩芽 / 小苗 / 花开 / 向阳 / 光芒）、学科进度条、每周周报（本地生成，可打印）
- 📊 **月历打卡热力图**：一格一天，按当日完成度着色，一眼看出这个月哪里坚持、哪里断了
- 🐷 **阳光存钱罐**：阳光按笔存入，每笔独立起息、满 7 天结算一次利息（利息复利入罐）；取出按先进先出，未满周期可选提前取出惩罚，界面提示「再存 X 天利息到账」
- 🎡 **惊喜盲盒抽奖**：Canvas 扇区 + 缓动停针；独立奖池（不与兑换商店混用），按概率加权抽样、含「谢谢参与」空奖位、每人限购、单次价格家长可配
- 🏅 **成就徽章**：12 枚徽章本地判定（打卡满 7/30/100 天、累计赚取 500/2000☀️、累计完成任务、每学科各 10 个任务、兑换满 10 件、存钱罐首笔利息、盲盒首次中奖），孩子端「我的徽章」可查看并佩戴，金级徽章佩戴期间任务得分 ×1.5（向下取整：+5 → +7）
- 🎨 **主题商店与明暗开关**：3 套可兑换主题包（海洋世界 / 森林秘境 / 太空漫游，纯 CSS 变量层）+ 免费内置「默认阳光绿」；色调与亮/暗正交（4 色调 × 2 模式 = 8 种外观），明暗是独立开关不会顶掉所选主题
- ⏱ **专注计时与多人竞速**：同屏多位孩子一起专注挑战，按用时排名
- 🎉 **即时反馈**：分档彩带 + WebAudio 合成提示音（完成双音 / 兑换琶音，无音频文件），家长可静音与调音量
- 📱 **移动端适配**：小屏与触屏下审批码、金额输入走大目标数字键盘（键高 ≥48px）

**家长侧 · 配置与管控**

- 👨‍‍👧 **多孩子档案**：同浏览器管理多名孩子，档案独立、随时切换；年级切换只换课本、不抹成长记录
- 🔢 **兑换审批码**：4–6 位数字审批码（本地 PBKDF2 哈希存储），兑换仅记账、现实放行由家长线下决定
- 📋 **待批准队列**：孩子可先「申请兑换」进队列（不扣分不发货），家长择时统一批准或拒绝并留回执
- ✏️ **内容全可编辑**：学科 / 单元 / 任务 / 奖励 / 等级规则增删改，拖拽排序；内置 1–6 年级课本样例可整体替换
- 🏷 **行为标签**：任务可选打标签（预置「学习 / 健康 / 责任 / 生活习惯」，也可自定义），统计侧按标签做第三维筛选与任务卡角标；标签不参与阳光计算
- 🖨 **打印 / A4 学习清单**：把任务清单打成纸质版贴在书桌上

**数据 · 安全与可迁移**

- 💾 **本地存储**：全部数据存浏览器 `localStorage`，刷新 / 重开不丢失
- 🛟 **快照兜底**：写盘自动轮换保留最近 8 份本机快照；主存档丢失时进入恢复面板（快照仅同浏览器有效）
- 📤 **导出 / 导入**：JSON 文件备份与换设备迁移，导出带元信息与校验和，导入前校验完整性；超过 14 天未导出会提醒
- ☁️ **可选 WebDAV 云同步**（默认关闭）：同步到自备网盘（NAS / Nextcloud）实现多端共享，凭证 AES-GCM 信封加密存储
- 🔐 **机密字段加密**：审批码 PBKDF2 哈希、云同步密码 AES-GCM 加密；阳光流水自动对账 + 裁剪，防串账

## 📥 安装

无需安装、无需构建，二选一：

```bash
# 方式 A：Clone 仓库（本仓库配置的 origin 地址）
git clone https://github.com/wangnan05563/sunshine-learning-station.git

# 方式 B：只要一个文件——把 阳光学习能量站.html 存到本地任意目录，双击即用
```

若上面这个地址当前不可达（仓库尚未推送或为私有），直接用方式 B：这个应用就是单个 HTML 文件，不需要仓库里的其他任何东西。

运行环境：现代桌面/平板浏览器（Chrome、Edge、Safari、Firefox 均可），全程可离线。

## ⚡ 快速开始

```text
1. 双击 阳光学习能量站.html 用浏览器打开
2. 进「家长中心」→ 新建孩子档案 → 选年级（载入课本样例任务）
3. 设一个 4–6 位兑换审批码，并按需增删任务与奖励
4. 把设备交给孩子：勾任务赚 ☀️ → 每日打卡攒连击 → 到兑换商店换奖励
```

首次打开会生成一份内置示例档案，可直接改、可整体清空，不影响后续使用。

## ⚙️ 配置

应用没有配置文件与环境变量，全部配置项在「家长中心」内可视化完成，并随应用数据一起存进 `localStorage`：

| 键 | 内容 |
|---|---|
| `sunshine_station_v1` | 主存档：档案、任务、奖励、主题、徽章、队列、同步配置等 |
| `sunshine_station_snapshots` | 本机快照轮换（上限 8 份，写盘 30s 节流） |
| `sunshine_station_kms` | 云同步凭证信封加密所需的本地密钥材料 |

家长侧可配项（节选）：任务与周期、奖励与库存、兑换审批码、存钱罐周利率、音效开关与音量、主题定价、云同步地址与账号（默认关闭）。

## 🧩 使用与程序接口

面向使用者是纯 UI 操作；面向自动化测试与二次开发，页面暴露一个受控命名空间：

```js
// 应用对外接口（单点入口，便于测试驱动与二次开发）
const App = window.__STUDY_APP__;

App.cur();                          // 当前孩子档案
App.addSunshine(5, "task", "完成任务");  // 阳光增减的唯一入口（倍率、流水都走这里）
App.settlePiggyInterest();          // 存钱罐满 7 天利息结算
App.evaluateBadges();               // 重算徽章达成
```

UI 交互采用事件委托（`data-act` 属性 → 分发表），新增动作只需注册一个 handler，不改渲染主流程。

## 💡 示例：一次完整的兑换

```text
孩子端                          家长端
1. 攒到 70☀️
2. 兑换商店点「申请兑换：看一集动画片」（内置样例，价 60☀️）
   → 进待批准队列，不扣分、不发货
3. 继续别的任务                    4. 家长中心 → 待批准队列看到这条申请
                                  5. 点「批准」→ 输入审批码 → 此刻才扣分、扣库存并写回执
                                  6. 点「拒绝」→ 置为已拒，阳光不动
```

自动化侧等价路径（同一套单入口，可直接在浏览器控制台跑）：

```js
const App = window.__STUDY_APP__;

App.addSunshine(70, "task", "示例：把阳光补到够兑换");
const r = App.state.rewards.find(x => x.title.includes("动画"));
App.applyRedeem(r.id);                                  // 孩子「申请兑换」：只进队列，不扣分
const req = App.cur().requests.find(x => x.status === "pending");

const ok = await App.verifyPin("2468", App.cur().pin);  // 审批码走本地 PBKDF2 校验
if (ok) await App.finalizeApprove(req.id);              // 批准那一刻才扣分、扣库存、写回执
```

## ⚠️ 已知限制

内容如实说明，避免误导：

- **回归脚本依赖本机环境**：`verify_dom_stub.js` 零依赖可直接跑；`verify_browser_real.js` 需要 Playwright 与本机 Chrome/Edge，脚本内以绝对路径引用浏览器驱动与证据输出目录，换机器需先装 Playwright 并调整这几处路径。
- **iOS Safari 真机未实测**：音频解锁手势与触屏键高在桌面浏览器的移动模拟下验证过，未覆盖 Apple 真机。
- **快照 ≠ 跨设备备份**：本机快照与主存档同生命周期，浏览器清缓存即失效；跨设备迁移只能靠「导出文件」或用户自启的云同步。
- **云同步需自备服务**：仅支持 WebDAV（NAS / Nextcloud 等），默认关闭，不提供托管存储。
- **兑换不构成授权**：兑换与审批码只做本地记账，现实活动的放行与陪同仍由家长线下决定。
- **导入仅接受本版格式**：更早期的「单档案」导出文件不再支持，需在本版重新导出后迁移。
- **AI 互动学习模块未实现**：PRD 中 OBS-01（AI 互动学习）按评审结论暂缓，当前版本没有任何相关能力。
- **课本样例仅供参考**：内置 1–6 年级目录是手工拆解的示例，非官方教材数据，应按下实际教材版本在家长中心改。
- **未指定许可证**：仓库当前没有 `LICENSE` 文件，因此本 README 不设「许可证」小节（不虚构未提供的事实）。

## 🔒 隐私与安全

- 默认**零网络**：不联网、不上传、无第三方上报与统计；唯一例外是用户主动启用的 WebDAV 云同步（仅向用户自备的网盘地址收发应用数据文件）。
- 审批码与同步密码等敏感字段均在本地加密 / 哈希后存储；导出文件含校验和，导入时校验完整性。
- 所有数据留在用户设备上，作者不持有任何用户数据。

## 🤝 贡献指南

1. Fork 本仓库并新建分支（`feat/<内容>` 或 `fix/<内容>`）。
2. 改动应用时请守住三条红线：**单文件**（不引入构建步骤与外部资源）、**默认零网络**、**阳光增减只经 `addSunshine` 单入口**。
3. 新特性补一条可复跑的断言：逻辑类进 `verify_dom_stub.js`，可见/可听类进 `verify_browser_real.js`。
4. 提交前本地跑：`node verify_dom_stub.js`（必须 0 failed）；涉及 UI/交互的再跑 `node verify_browser_real.js`。
5. 开 PR 时说明动机、影响范围与验证方式；一个 PR 只做一件事。
